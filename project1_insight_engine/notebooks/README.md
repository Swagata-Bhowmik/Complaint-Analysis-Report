# notebooks/

Step-by-step Jupyter notebooks, one per phase. Each notebook is written to be read top-to-bottom:
every code cell has a header, comments, an explanation of what it does, and an interpretation of
its output.

- `phase1_data.ipynb` — get & understand the CFPB data
- `phase2_clean.ipynb` — clean & prepare the complaint text
- `phase3_engine.ipynb` — the NLP engine prototyped on an 18k sample
- `phase3_full_depth.ipynb` — the same engine's full depth story on the real **112,481**
  complaint dataset (the actual deliverable the app is built on), including an honest
  comparison of what changed between the sample and the full run, business insights,
  stated limitations, and an interview-prep recap.
